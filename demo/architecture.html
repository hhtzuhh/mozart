System architecture

Mozart watches a simulated pianist, chooses a change to its hand movements, and listens to the next take. Each practice strategy runs its own rehearsal loop.

Inside one rehearsal round

  1. Gemini · Neon

    Diagnose

    Read the target and played keys alongside the performance video and audio. Identify a passage, hand, and movement to test.

  2. Gemini · Hydrogen

    Choose an edit

    Select from the proposed changes. The local runner applies the selection to a copy of the retained hand trajectories.

  3. Modal · NVIDIA T4

    Replay

    PianoMime plays the full score with the edited trajectories and the same seed. The worker returns a video, key trace, log, and metrics.

  4. Local runner

    Score

    Compare the replay with its parent across the entire clip. A higher mean frame F1 makes this take the starting point for the next round.

↶ Next round uses the retained take and feedback from the previous trial.

Where calls run in parallel

The four-strategy matrix starts independent branches from the same baseline. Each branch calls Gemini and submits its own replay to a shared Modal worker pool. Within one branch, the next round waits for the score.
